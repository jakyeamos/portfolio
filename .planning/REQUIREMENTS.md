# Requirements: portfolio

**Defined:** 2026-04-10
**Core Value:** The live portfolio should accurately represent current owned work and stay deployable from main.

## v1 Requirements

### Release Baseline

- [ ] **PORT-01**: Visitors see only current owned projects in the active-project list.
- [ ] **PORT-02**: The React/Vite portfolio builds cleanly from the current repo state.
- [ ] **PORT-03**: The authoritative portfolio implementation is clear and ready to merge to main.
- [ ] **PORT-04**: Release prep work documents what remains before the site can be confidently published.

## v2 Requirements

### Follow-on Polish

- **PORT-05**: The repo has a cleaner asset strategy for large binaries and drafts.
- **PORT-06**: Deployment verification is automated or at least repeatable.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Showcasing projects that are not owned work | That creates portfolio drift and weakens trust. |
| Parallel maintenance of two different portfolio implementations | The SPA should become the authoritative product. |
