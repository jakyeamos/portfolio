# 04-03 Plan: Product Repo Branch and Commit Protocol

## Goal

Define how future product hardening sessions should work without mixing with
existing dirty worktrees or active feature branches.

## Target Repos

All repos listed in `04-01-PLAN.md`.

## Deliverable

- `.planning/interview-surface/product-branch-commit-protocol.md`

## Steps

- [ ] Define pre-work checks: branch, status, remote, recent commits, and truth file presence.
- [ ] Define when to create a feature branch or worktree.
- [ ] Define how to handle existing unrelated changes without reverting them.
- [ ] Require atomic commits and `.tracker/PROJECT_TRUTH.md` updates when truth files exist.
- [ ] Require push after each completed public-readiness sprint when remote workflow permits.
- [ ] Update `.planning/STATE.md` with Phase 4 completion notes.

## Commit Strategy

Commit Phase 4 outputs together as `docs: plan product repo hardening`.
